# Cadre logique MEverse

Un `me_project` a au plus UN `me_logframe` actif (cardinalite 0..1).

## Usage

``` r
me_logframe(goal = character(0), results = list(), hypotheses = character(0))
```

## Arguments

- goal:

  Objectif general.

- results:

  Liste de `me_result`.

- hypotheses:

  Liste de chaines de caracteres (hypotheses/risques).
