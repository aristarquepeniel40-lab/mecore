# Instancier un me_indicator a partir d'un code ODD standard

Instancier un me_indicator a partir d'un code ODD standard

## Usage

``` r
me_indicator_from_sdg(code, datasets, formula, value = NULL)
```

## Arguments

- code:

  Code de l'indicateur standard (ex. "4.1.1").

- datasets:

  Liste de `me_dataset` sources.

- formula:

  Formule de calcul specifique au contexte du projet.

- value:

  Valeur calculee (optionnelle a la creation).
