# Lever une erreur de dependance manquante (ex. package Suggests absent)

Lever une erreur de dependance manquante (ex. package Suggests absent)

## Usage

``` r
me_dependency_error(message, ...)
```

## Arguments

- message:

  Message d'erreur affiche a l'utilisateur.

- ...:

  Donnees additionnelles attachees a la condition.
