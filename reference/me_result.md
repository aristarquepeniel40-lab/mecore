# Resultat d'un cadre logique

Resultat d'un cadre logique

## Usage

``` r
me_result(label = character(0), indicators = list())
```

## Arguments

- label:

  Libelle du resultat (ex. "R1 : acces ameliore aux services").

- indicators:

  Liste de `me_indicator` associes (peut etre vide en construction).
