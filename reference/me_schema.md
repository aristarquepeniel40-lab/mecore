# Contrat de schema (ensemble de champs attendus)

Regroupe plusieurs `me_schema_field` pour decrire l'ensemble des
colonnes attendues d'un dataset. Voir
[`check_schema()`](https://aristarquepeniel40-lab.github.io/mecore/reference/check_schema.md)
pour la verification effective.

## Usage

``` r
me_schema(fields = list())
```

## Arguments

- fields:

  Liste de `me_schema_field`.
